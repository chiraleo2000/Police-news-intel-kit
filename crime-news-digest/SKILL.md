# Crime News Digest — Agent สรุปข่าวอาชญากรรมประจำวัน (ข้อความ + Infographic ตามสั่ง)

Skill นี้ให้ Claude ทำหน้าที่เป็น Agent ค้นหา คัดกรอง จัดกลุ่ม และสรุปข่าวประจำวัน มี **2 โหมด**
แยกจากกัน เลือกตามที่ผู้ใช้ขอ:

| โหมด | ผู้ใช้ขอว่า | คัดข่าวอย่างไร | จัดกลุ่มตาม | ฟอร์มข้อความ |
|---|---|---|---|---|
| **A. ข่าวประจำวัน 9 แท็ก** | "สรุปข่าวอาชญากรรมออนไลน์ …" | เฉพาะข่าวที่เข้า 1 ใน 9 แท็ก | ข่าวทีละข่าว (เรียงตามลำดับแท็ก) | ฟอร์ม A |
| **B. ข่าวจาก บช.** | "สรุปข่าวจาก บช. …" | **ทุกประเภทข่าว ไม่จำกัดหมวด** ขอแค่เกี่ยวข้องกับ บช. | แยกตาม บช. | ฟอร์ม B |

ถ้าผู้ใช้ไม่ได้ระบุว่าโหมดไหน และคำขอกำกวม (เช่น "สรุปข่าวตำรวจวันนี้") ให้ถาม 1 คำถามสั้นๆ ว่าต้องการโหมดไหน
ถ้าผู้ใช้ขอทั้งสองอย่างก็ทำทั้งสองโหมด แยกเป็น 2 ข้อความ

## หลักการส่งมอบ (สำคัญ)

- **ค่าเริ่มต้นคือ "ข้อความ" เท่านั้น** ตามฟอร์มด้านล่าง ตอบในแชทได้เลย (วางในกล่องโค้ดเพื่อให้คัดลอกไป LINE แล้วเครื่องหมาย `*` ตัวหนาและการย่อหน้าไม่เพี้ยน)
- **Infographic (.jpeg ฟอนต์ Kanit) จะสร้างต่อเมื่อผู้ใช้สั่งให้สร้างเท่านั้น** (เช่น "ทำเป็น Infographic", "ขอเป็นภาพ")
  อย่าสร้างเองโดยไม่ถูกสั่ง และอย่าเสนอซ้ำๆ — พอแจ้งท้ายข้อความ 1 ครั้งว่าสร้างให้ได้เมื่อสั่ง ก็พอ
- ไม่ต้องเขียนไฟล์ .txt ส่งให้ ยกเว้นผู้ใช้ขอเป็นไฟล์

## ขอบเขตวันที่ (ใช้กับทั้งสองโหมด)

ต้องเป็นข่าวที่ **เผยแพร่ในวันที่ผู้ใช้ระบุเท่านั้น** — ยึด **วันที่เผยแพร่บทความ**
(meta `article:published_time` หรือบรรทัดวันที่ของสำนักข่าวในหน้าเว็บ) **ไม่ใช่วันที่เกิดเหตุในเนื้อข่าว**
เช่น ข่าวที่เผยแพร่ 21 ต.ค. แต่เหตุเกิดเย็น 20 ต.ค. → นับเป็นข่าววันที่ 21 ต.ค.
ถ้าผู้ใช้ไม่ระบุวันที่ = วันนี้ (เรียกเครื่องมือเวลาปัจจุบันเพื่อยืนยันวันที่ ห้ามเดา)

ใช้ `WebFetch` เปิดอ่านข่าวเต็มเพื่อยืนยันวันที่เผยแพร่จริงก่อนนำมาใช้เสมอ (ผลค้นหามักปนข่าวเก่า)

**ถ้าค้นแล้วไม่พบ/พบน้อย** (มักเกิดถ้าค้นตอนเช้า) ให้แจ้งผู้ใช้ตรงๆ พร้อมเสนอทางเลือก (รันซ้ำช่วงบ่าย/เย็น
หรือรวมข่าววันก่อนหน้า) **ห้ามหยิบข่าววันอื่นมาใส่แทนโดยไม่ถามและไม่บอก**
ถ้าผู้ใช้ยืนยันให้รวมข่าวข้ามวัน ต้องระบุวันที่เผยแพร่จริงกำกับไว้ในข่าวนั้นและแจ้งในสรุปท้ายข้อความ

# โหมด A — ข่าวประจำวัน 9 แท็ก

## หมวดคดี 9 แท็ก

แต่ละข่าวติดแท็กเดี่ยว 1 แท็ก:

**กลุ่มอาชญากรรมออนไลน์ (แยกตามพฤติการณ์หลักของคดี):**
1. หลอกลวงด้านการเงินและการลงทุน
2. หลอกลวงโดยการแอบอ้างบุคคลอื่น
3. หลอกลวงด้านสินค้าและบริการ
4. หลอกลวงด้านการจ้างงาน
5. การโจมตีทางเทคนิคเชิงรุก (แฮก/เจาะระบบ/ฟิชชิ่งเชิงเทคนิค)
6. ประเภทคดีฉ้อโกงทางเทคโนโลยีอื่น ๆ ซึ่งมิได้จัดประเภทไว้ที่อื่น (เช่น เครือข่ายบัญชีม้า/รับจ้างถอนเงินสนับสนุนแก๊งสแกมเมอร์ ที่ไม่เข้าเกณฑ์ข้อ 1-5 ชัดเจน)

**กลุ่มอื่น:**
7. พนันออนไลน์
8. ค้ามนุษย์
9. นโยบาย (ข่าวระดับรัฐบาล/หน่วยงานประกาศความร่วมมือปราบอาชญากรรม ไม่ใช่ข่าวจับกุมโดยตรง — ใส่เฉพาะเมื่อผู้ใช้ยืนยันหรือส่งลิงก์มาเอง)

**กติกาเลือกแท็ก:** เลือกตาม "พฤติการณ์หลัก/เทคนิคการหลอกลวง" เช่น สวมรอยเป็นคนรู้จักเพื่อหลอกโอนเงินค่าสินค้า
→ "หลอกลวงโดยการแอบอ้างบุคคลอื่น" (ไม่ใช่สินค้าและบริการ เพราะกลไกหลักคือการแอบอ้างตัวตน)
ถ้าเป็นการเปิดร้านปลอมขายของไม่ส่งของโดยตรง → "หลอกลวงด้านสินค้าและบริการ"

## ขั้นตอน
1. ค้นทีละแท็ก อย่ารวมทุกหมวดในคำค้นเดียว เช่น `หลอกลงทุนออนไลน์ จับกุม [วันที่]`, `สวมรอยแอบอ้าง หลอกโอนเงิน [วันที่]`,
   `พนันออนไลน์ จับกุม [วันที่]`, `ค้ามนุษย์ [วันที่]` แล้วเปิดอ่านข่าวยืนยันวันที่เผยแพร่
2. จัดข้อมูลเป็น JSON (สคีมาด้านล่าง) โดยแต่ละ category = 1 แท็ก (`title` = ชื่อแท็กเป๊ะๆ)
3. สร้างข้อความ: `python3 scripts/json_to_text.py --mode 9tag <ไฟล์.json>` (หรือเขียนเองให้ตรงฟอร์ม A ทุกตัวอักษร)

## ฟอร์ม A — ข้อความข่าว 9 แท็ก (ต้องตรงตามนี้)

```
*สรุปข่าวอาชญากรรมออนไลน์ วันที่ (วัน) (เดือน) (ปี)*
*1. (ชื่อข่าว)*
      (สรุปเนื้อหาข่าวเป็นประเด็นที่สำคัญ)
      *ประเภทคดี :* (ประเภทคดี)
      *พื้นที่ :* (พื้นที่เกิดเหตุ)
      *สถานะ :* (สถานะคดี)
      *มูลค่าความเสียหาย :* (มูลค่าความเสียหาย)
      *ชื่อกลุ่ม/แก๊ง :* (ชื่อกลุ่ม/แก๊ง)
      *อ้างอิง :* (ลิงก์ข่าว)
(ถ้ามีมากกว่า 1 ข่าวก็ใส่ 2. 3. ตามลำดับ)
```

- บรรทัดสรุปข่าวและบรรทัดรายละเอียด (ประเภทคดี ถึง อ้างอิง) **ไม่มีเลขข้อกำกับและไม่มีหัวข้อ "สรุปข่าว"** เลขข้อมีเฉพาะชื่อข่าว
- ประเด็นสำคัญแต่ละข้อขึ้นบรรทัดใหม่ ย่อหน้า 6 ช่องว่างเท่ากับบรรทัด ประเภทคดี (ไม่ต้องใส่เครื่องหมายหัวข้อ)
- `(เดือน)` เป็นชื่อเดือนภาษาไทยเต็ม `(ปี)` เป็น พ.ศ. เช่น "16 สิงหาคม 2569"
- `ประเภทคดี` = ชื่อแท็กของข่าวนั้น (ใช้ `caseType` ถ้าต้องการอธิบายเพิ่ม)
- เลข "1.1." ในบรรทัดสรุปข่าวมีจุดต่อท้ายตามฟอร์มต้นฉบับ (บรรทัดอื่นไม่มี)

# โหมด B — ข่าวจาก บช. (ทุกประเภทข่าว)

## นิยาม "ข่าวที่เกี่ยวข้องกับ บช."

เก็บข่าว **ทุกประเภท ไม่จำกัดว่าเป็นอาชญากรรมออนไลน์** (ยาเสพติด ฆาตกรรม จับหมายแดง ปล้น อุบัติเหตุที่ตำรวจแถลง
คดีทุจริต พนัน ค้ามนุษย์ นโยบาย ฯลฯ) ขอเพียงข่าวนั้น **ระบุ บช. เป็นหน่วยปฏิบัติ/หน่วยแถลง/หน่วยที่เกี่ยวข้อง**
เช่น ข่าวที่เอ่ยถึง ผบช.xx, รอง ผบช.xx, บก./กก.ใต้สังกัด บช.xx หรือแถลงที่ บช.xx

บช. ที่ต้องค้น (ค้นแยกทีละ บช. อย่ารวมคำค้น):
- บช.ก. (กองบัญชาการตำรวจสอบสวนกลาง / CIB รวมกองปราบ บก.ปพ.)
- บช.น. (กองบัญชาการตำรวจนครบาล)
- บช.ปส. (กองบัญชาการตำรวจปราบปรามยาเสพติด)
- บช.สอท. (กองบัญชาการตำรวจสืบสวนสอบสวนอาชญากรรมทางเทคโนโลยี / "ตำรวจไซเบอร์")
- บช.สตม. (สำนักงานตรวจคนเข้าเมือง / ตม.)
- บช.ตชด. (กองบัญชาการตำรวจตระเวนชายแดน)
- บช.ภ.1–9 (กองบัญชาการตำรวจภูธรภาค 1–9)
- บช. อื่นที่พบในข่าว (เช่น บช.ส. บช.ทท.) ให้รวมด้วย

**ไม่นับ:** ข่าวที่ระบุเพียงสถานีตำรวจ/ภ.จว. (เช่น สภ.xx, ตร.ภ.จว.xx) โดยไม่มี บช. ปรากฏในข่าว — ไม่ต้องเดาว่าอยู่ใต้ บช.ไหน
ให้แจ้งผู้ใช้ท้ายข้อความว่ามีข่าวลักษณะนี้ที่ไม่ได้นับ

## ขั้นตอน
1. ค้นข่าวทีละ บช. ตามรายการข้างต้น (เช่น `บช.สอท. ตำรวจไซเบอร์ จับกุม [วันที่]`, `บช.ปส. ยาเสพติด [วันที่]`)
   แล้วเปิดอ่านข่าวยืนยันวันที่เผยแพร่และข้อมูลครบถ้วน
2. จัดกลุ่มตาม บช. — **ข่าวที่เกี่ยวข้องหลาย บช. ให้ใส่ใต้ บช. หลักที่เป็นผู้ปฏิบัติ/แถลง เพียงที่เดียว** และเอ่ยถึง บช. ร่วมในประเด็นสรุป
   (ห้ามซ้ำข่าวเดียวกันหลายที่) ลำดับ บช. ในข้อความเรียงตามรายการข้างต้น
3. ข่าวที่มีหลายแหล่ง (สำนักข่าวหลายเจ้ารายงานเรื่องเดียวกัน) ให้รวมเป็นข่าวเดียว ใส่ลิงก์อ้างอิงหลายลิงก์ได้
   ถ้าแหล่งข่าวรายงานไม่ตรงกัน (เช่น ชื่อ/ตัวเลข) ให้ระบุว่าแหล่งไหนรายงานอย่างไร ห้ามเลือกเอง
4. จัดข้อมูลเป็น JSON (สคีมาด้านล่าง) โดยแต่ละ category = 1 บช. (`title` เช่น "บช.ปส. (กองบัญชาการตำรวจปราบปรามยาเสพติด)")
5. สร้างข้อความ: `python3 scripts/json_to_text.py --mode bch <ไฟล์.json>` (หรือเขียนเองให้ตรงฟอร์ม B ทุกตัวอักษร)

## ฟอร์ม B — ข้อความข่าวจาก บช. (ต้องตรงตามนี้)

```
*สรุปข่าวจาก บช. วันที่ (วัน) (เดือน) (ปี)*
*1. (ชื่อบช.)*
   *1.1 (ชื่อข่าว)*
      (สรุปเนื้อหาข่าวเป็นประเด็นที่สำคัญ)
      *ประเภทคดี :* (ประเภทคดี)
      *พื้นที่ :* (พื้นที่เกิดเหตุ)
      *สถานะ :* (สถานะคดี)
      *มูลค่าความเสียหาย :* (มูลค่าความเสียหาย)
      *ชื่อกลุ่ม/แก๊ง :* (ชื่อกลุ่ม/แก๊ง)
      *อ้างอิง :* (ลิงก์ข่าว)
(ถ้ามีมากกว่า 1 ข่าวใน บช. เดียวกันก็ใส่ 1.2 1.3 ตามลำดับ)
(ถ้ามี บช. อื่น ใส่ 2. 3. 4. ตามลำดับ)
```

- เลขข้อมีเฉพาะ บช. (1. 2. 3.) และชื่อข่าว (1.1, 1.2 / 2.1, 2.2 …) ตามลำดับ ส่วนบรรทัดสรุปและบรรทัดรายละเอียด
  (ประเภทคดี ถึง อ้างอิง) **ไม่มีเลขข้อกำกับและไม่มีหัวข้อ "สรุปข่าว"** (ดูตัวอย่าง `examples/bch-2569-10-21.txt`)
- ประเด็นสำคัญแต่ละข้อขึ้นบรรทัดใหม่ ย่อหน้า 6 ช่องว่างเท่ากับบรรทัด ประเภทคดี (ไม่ต้องใส่เครื่องหมายหัวข้อ)
- `ประเภทคดี` ในโหมดนี้เป็นข้อความอธิบายอิสระ (ไม่ต้องตรงแท็ก 9 แท็ก) เช่น "คดียาเสพติด (ลักลอบลำเลียงไอซ์ข้ามภาค)"
  ถ้าไม่ใช่คดีอาชญากรรมให้ระบุชนิดเหตุตามจริง เช่น "การแถลงผลงาน", "อุบัติเหตุ"
- บช. ที่ไม่พบข่าวของวันนั้นไม่ต้องใส่ในข้อความ (แต่ให้บอกในสรุปท้ายข้อความว่า บช. ไหนไม่พบข่าว)

## สคีมา JSON (ใช้ทั้งสองโหมด และใช้สร้าง Infographic)

```json
{
  "dateLabel": "21 ตุลาคม 2569",
  "heading": "สรุปข่าวจาก บช. วันที่ 21 ตุลาคม 2569",
  "categories": [
    { "title": "<โหมด A: ชื่อแท็ก | โหมด B: ชื่อ บช.>",
      "items": [
        { "title": "ชื่อข่าว",
          "points": ["ประเด็นสำคัญข้อ 1", "ข้อ 2"],
          "caseType": "ประเภทคดี (ไม่ใส่ได้ในโหมด A = ใช้ชื่อแท็ก)",
          "location": "พื้นที่เกิดเหตุ หรือ -",
          "status": "สถานะคดี หรือ -",
          "damage": "มูลค่าความเสียหาย หรือ -  (null = ไม่แสดงบรรทัด)",
          "gang": "ชื่อกลุ่ม/แก๊ง หรือ -  (null = ไม่แสดงบรรทัด)",
          "ref": "ลิงก์ข่าว หรือ [ลิงก์1, ลิงก์2]" } ],
      "note": "(ไม่บังคับ) เหตุผลที่ไม่พบข่าวในหมวดนี้" }
  ]
}
```
- `heading` (ไม่บังคับ) ใช้เป็นหัวเรื่องบน Infographic ถ้าไม่ใส่จะใช้ "สรุปข่าวอาชญากรรมออนไลน์ประจำวันที่ <dateLabel>"
- category ที่ `items` ว่างจะถูกข้ามทั้งในข้อความและ Infographic
- ข่าวหมวด "นโยบาย" (โหมด A) ให้ตั้ง `"damage": null` และ `"gang": null` เพื่อไม่แสดงสองบรรทัดนี้
- ตัวอย่างไฟล์จริง: `examples/2569-08-16.json` (โหมด A), `examples/bch-2569-10-21.json` (โหมด B)

## สร้าง Infographic (เฉพาะเมื่อผู้ใช้สั่ง)

```bash
bash scripts/install_font.sh          # ถ้ายังไม่มีฟอนต์ Kanit (ตรวจด้วย fc-list | grep -i kanit)
bash scripts/render_infographic.sh <ไฟล์.json> <ชื่อไฟล์ผลลัพธ์ไม่ใส่นามสกุล>
```
- ใช้ JSON ชุดเดียวกับที่สร้างข้อความ (โหมด B: แต่ละ บช. จะแสดงเป็นแท็กสีส้มบนการ์ดข่าว, หัวเรื่องมาจาก `heading`)
- Infographic แสดง ชื่อข่าว / แท็ก(หรือ บช.) / ประเด็นสำคัญ / มูลค่าความเสียหาย / ชื่อกลุ่ม-แก๊ง / อ้างอิง
  (ไม่แสดงประเภทคดี/พื้นที่/สถานะ — ข้อมูลเหล่านี้อยู่ในข้อความ)
- ได้ `.jpeg` ไฟล์เดียว ฟอนต์ Kanit โทนกรมท่า-ส้ม-ขาว ไฟล์ HTML ระหว่างทางเป็นไฟล์ชั่วคราว ไม่ส่งมอบ
- ชื่อไฟล์ส่งมอบ: `สรุปข่าวอาชญากรรมออนไลน์_<วันที่>_infographic.jpeg` (โหมด A) / `สรุปข่าวจาก_บช_<วันที่>_infographic.jpeg` (โหมด B)

## กติกาความถูกต้อง (สำคัญมาก ใช้ทั้งสองโหมด)

- ห้ามใส่ชื่อ "แก๊ง"/กลุ่มองค์กรอาชญากรรม เว้นแต่ข่าวต้นทางระบุชื่อไว้ชัดเจน — ถ้าไม่ระบุให้ใส่ "-" (จะเติมวงเล็บอธิบายสั้นๆ ว่าข่าวระบุอะไรได้ เช่น "เครือข่ายของนาย X" แต่ห้ามตั้งชื่อเอง)
- ห้ามเดา/แต่งตัวเลขความเสียหายหรือสถานะคดีที่ข่าวไม่ได้ระบุ — ใส่ "-" (ถ้ามีของกลางให้ระบุของกลางในวงเล็บ ไม่ใช่มูลค่าที่ไม่มีในข่าว)
- คดีที่ยังไม่มีคำพิพากษา ระบุสถานะว่า "อยู่ระหว่างสอบสวน/ดำเนินคดี" หรือสถานะจริงตามข่าวเท่านั้น (เช่น "จับกุมแล้ว", "ผู้ต้องหาเสียชีวิต")
- ข่าวที่ผู้ต้องหาเสียชีวิตจากการปะทะ ให้ใช้ถ้อยคำตามข่าว ไม่ตัดสินความถูกผิดของเจ้าหน้าที่หรือผู้ต้องหา
- ห้ามหยิบข่าววันอื่นมาใส่แทนโดยไม่บอกผู้ใช้ เกณฑ์วันที่ยึดวันที่เผยแพร่บทความเสมอ
- เนื้อหาสรุปต้องเรียบเรียงใหม่ด้วยคำพูดของตัวเอง ห้ามคัดลอกข้อความต้นฉบับแบบคำต่อคำ (ลิขสิทธิ์)
- ชื่อบุคคลที่ข่าวใช้นามสมมติให้คงนามสมมติตามข่าว
- ควรมีผู้ตรวจสอบความถูกต้องก่อนเผยแพร่ในวงกว้าง โดยเฉพาะกรณีมีชื่อบุคคล/องค์กรที่กระทบชื่อเสียง

## สรุปท้ายข้อความ (เขียนหลังกล่องข้อความทุกครั้ง สั้นๆ)

- จำนวนข่าวที่นับ และ (โหมด B) จำนวนต่อ บช.
- ข่าวที่เจอแต่ไม่นับ พร้อมเหตุผล (เผยแพร่คนละวัน / ไม่ระบุ บช.)
- แท็ก/บช. ที่ไม่พบข่าว
- ถ้าค้นตอนเช้าและข่าวยังน้อย ให้เสนอรันซ้ำช่วงบ่าย/เย็น
- บอก 1 ครั้งว่าสร้าง Infographic ให้ได้เมื่อสั่ง
- ปิดท้ายด้วยรายการ "Sources:" (ชื่อข่าว + ลิงก์)

## การติดตั้ง (Installation)

**สำหรับ Claude.ai / Claude Cowork (Skills แบบอัปโหลด):**
1. ไฟล์ `crime-news-digest.zip` ที่แนบมาพร้อมใช้งานแล้ว (มี `SKILL.md`, `scripts/`, `examples/`, `fonts/`) ไม่ต้องบีบอัดซ้ำ
2. ไปที่ Settings → Capabilities/Skills → Upload skill แล้วเลือกไฟล์ .zip นี้ (ถ้ามี skill ชื่อเดิมอยู่ ให้อัปโหลดทับเวอร์ชันใหม่)
3. เปิดใช้งาน (toggle on) skill ในการสนทนาที่ต้องการใช้ พร้อมเปิด **Web Search**

**สำหรับ Claude Code / เครื่องที่มี computer/bash tool:**
1. แตกไฟล์ .zip แล้วคัดลอกโฟลเดอร์ `crime-news-digest/` ไปไว้ที่ `/mnt/skills/user/crime-news-digest/` (หรือ path skills ของระบบคุณ)
2. สร้างข้อความ (ทั้งสองโหมด) ต้องการเพียง `python3` (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)
3. สร้าง Infographic (ต้องการเฉพาะเมื่อสั่ง) ติดตั้งครั้งเดียว:
   ```bash
   sudo apt-get install -y wkhtmltopdf   # มี wkhtmltoimage อยู่ในแพ็กเดียวกัน (ใช้แปลง HTML -> JPEG)
   bash scripts/install_font.sh          # ติดตั้งฟอนต์ Kanit
   fc-list | grep -i kanit               # ควรเห็น "Kanit"
   ```
   และต้องมี `node` สำหรับ `build_infographic_html.js`

> "สรุปข่าวจาก บช.สอท. กับ บช.ปส. วันที่ 20 ตุลาคม 2569"

## Input ที่ต้องใส่

| Input | บังคับ/ไม่บังคับ | ตัวอย่าง |
|---|---|---|
| โหมด (9 แท็ก / ข่าวจาก บช.) | บังคับ (ถ้ากำกวม Claude จะถาม) | "ข่าวอาชญากรรมออนไลน์", "ข่าวจาก บช." |
| วันที่ต้องการสรุป | ไม่บังคับ (ค่าเริ่มต้น = วันนี้) | "16 สิงหาคม 2569", "เมื่อวาน", "วันนี้" |
| ขอบเขต (ถ้าต้องการเจาะจง) | ไม่บังคับ | "เฉพาะพนันออนไลน์", "เฉพาะ บช.สอท." |
| ลิงก์ข่าวที่อยากให้เพิ่มเอง | ไม่บังคับ | วางลิงก์ข่าวมาในแชทได้เลย |
| สั่งสร้าง Infographic | ไม่บังคับ (ไม่สั่ง = ได้ข้อความอย่างเดียว) | "ทำเป็น Infographic" |
