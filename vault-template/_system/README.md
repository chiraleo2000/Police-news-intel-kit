| มนุษย์เขียน | `00_Inbox`, `60_Notes`, `70_Canvas` | คุณ | ลิงก์ไปยังโน้ตอัตโนมัติด้วย `[[case_id]]` ได้ |

## กฎ 5 ข้อ
1. อยากเขียนวิเคราะห์เอง → สร้างโน้ตใน `60_Notes` แล้วลิงก์ `[[2026-10-21-cyber-001]]` ไป ไม่ต้องแก้โน้ตอัตโนมัติ
2. ห้ามเปลี่ยนชื่อไฟล์ใน `20_Cases` และ `30_Entities` (server ใช้ชื่อเป็นกุญแจ; เปลี่ยนชื่อ = สร้างซ้ำ)
3. ต้องการชื่อมาตรฐานใหม่ → เพิ่มใน `_system/canonical-entities.md` ก่อน (server อ่านไฟล์นี้ตอนสร้างโน้ต)
4. vault มีชื่อ/คดีจริง ห้ามเปิดสาธารณะ ห้ามซิงก์ขึ้นที่ที่คนนอกทีมเข้าถึงได้
5. ต้องการลบข้อมูลคดีใดออก → ลบที่ news-hub (DB) แล้วรัน `vault-build`; การลบไฟล์ใน vault อย่างเดียวจะถูกสร้างกลับ
